# About Bob

If something isn't going as fast as it possibly can, I want to know why — and
then I want to fix it. That impulse is the thread running through all of
this.

**Career 1.0** was compilers, operating systems, and network stacks — the layers
everything else stands on.

**Career 2.0** was messaging software startups and reliable multicast: getting
the same data to many places at once, quickly, without losing any of it.

**Career 3.0** was electronic trading and market structure research at Citadel
Securities, where the question of what "fast" means gets unusually precise.

**Retirement 1.0** was microcontrollers, 3D printing, Proxmox, and upgrading
the house to 10 GbE.

**Retirement 2.0** is researching the limits of practically precise timekeeping —
not the theoretical floor, but how close you can actually get with equipment you
can buy and run yourself.

This blog is where I write down what I find out. The name plays on "think
outside the box."

# Colophon

## Built With

[Astro](https://astro.build) 7, with posts written in MDX and images resized at
build time by [sharp](https://sharp.pixelplumbing.com/). Node 24. The whole
site is static — every page is a file, generated ahead of time, with nothing
assembled while you wait.

The [source is on GitHub](https://github.com/bobvan/outsideTheBob), including
the scripts that generate the artwork.

## Hosted On

[Cloudflare Workers](https://workers.cloudflare.com/). Pushing to `main` is the
deploy: Cloudflare watches the branch, runs the build, and publishes the result.
There is no server and no Worker code — the configuration says *serve these
files*, and Cloudflare serves them from wherever you happen to be.

It used to run on GitHub Pages behind Cloudflare, which meant two systems that
each thought they were in charge of the site. Now there is one. The domains are
on Cloudflare's DNS too; **ThinkOutsideTheBob.Com** is the real one and
**OutsideTheBob.Com** is a shortcut that redirects to it, keeping whatever path
you arrived with.

Neither domain sends or accepts mail, and both say so in DNS — if something
claims to be email from here, it isn't.

## Nothing Comes From Anywhere Else

No analytics scripts, no advertising, no webfonts, no libraries pulled from a
CDN, no cookies, no trackers. **Your browser fetches nothing from anyone else
while reading this — until you click a link that leaves.**

That isn't an accident of a small site; it's the thing I check before adding
anything. A charting library I tried briefly would have loaded itself from a
CDN on every page view, which is how I ended up publishing charts as plain
images instead.

Traffic is counted at Cloudflare's edge as requests pass through, which needs no
JavaScript on the page and sets nothing in your browser — and now that Cloudflare
is also the host, it is simply a byproduct of serving the file. I get to know
which posts people read. You don't get followed around the internet. This seems
like the right trade.

## Typography

Body text is set in whatever sans-serif your system already has — `system-ui`
first, then the usual fallbacks. Nothing to download, which is both faster for
you and one less request leaving your machine.

The wordmark is [Inter](https://rsms.me/inter/) Display Black, by Rasmus
Andersson, under the SIL Open Font License.

## The Logo

"Think" sits inside the box; "OutsideTheBob" smashes out through the right wall
and climbs away, scattering fragments. The joke only works if the wall is
actually broken, so it is — the box is drawn with a gap where the wordmark
passes through, rather than a rectangle with something laid over it.

It's generated rather than drawn. A script reads Inter's glyph outlines and
kerning with [fontkit](https://github.com/foliojs/fontkit) and converts the
lettering to paths, so it renders identically everywhere instead of depending
on which fonts a viewer happens to have. The debris radiates from the point of
rupture at computed angles, and the script refuses to place a fragment that
would collide with the lettering. The social preview card is rendered from the
same file by sharp, so the two can't drift apart.
