# Figures — the contrast set

Companion to `docs/glossary-research.md`. Generated by `scripts/make-figures.mjs`
(`npm run figures`) into `public/figures/`, shown on the existing
`figure.diagram` light plate so line art stays readable in dark mode.

## Working rules, after Tufte

*Visual Explanations* and *Envisioning Information* both push the same device
and it is the right one here: **small multiples**. The same frame repeated with
exactly one variable changed, adjacent in space so the eye does the comparing.

1. **One variable per direction.** If two panels differ in more than one way the
   reader cannot tell which difference caused what. This is the rule the first
   draft of the 2×2 broke — both axes were labelled as rows.
2. **Direct labelling.** No legends. A legend makes the reader hold a key in
   working memory while looking somewhere else.
3. **The ink is the data.** No fills, gradients, 3-D, or decoration.
4. **Identical data across panels wherever the point is about the frame.** In
   *where-is-utc* the shots are literally the same numbers on both sides; only
   the frame differs, which is the entire argument.
5. **Each figure has one sentence it exists to make unavoidable.** If it needs a
   paragraph, it is two figures.
6. **Deterministic.** Shot positions come from a seeded PRNG, so a rebuild is
   byte-identical and a diff means something changed on purpose.

## Drawn

| Figure | The one sentence | Used on |
|---|---|---|
| `trueness-precision` | Accuracy is not an axis, it is the corner where trueness and precision are both good. | *Contrasting timing accuracy and precision* |
| `where-is-utc` | The shots are identical; only the frame differs, and the frame is what you do not have. | same page |
| `resolution-ladder` | Coarse resolution does not limit precision, it counterfeits it. | *Relating timing accuracy with measurement resolution* |
| `agreement-vs-truth` | The ensemble that is worse against UTC is better at everything the application computes. | *"It matters more that my clocks agree…"* |

`agreement-vs-truth` carries the statistics bridge Bob asked for: the same two
ensembles as targets on top and as normal curves with μ and σ below, to the same
horizontal scale. Readers who think in distributions get the argument in their
own notation without the target being dumbed down for them.

## Worth drawing next

- **The averaging arrow.** Two panels: a loose group, then the same group
  tightened, with the centre marked in both to show it has not moved. Currently
  the strongest idea not yet drawn, because it converts the static grid into the
  claim that actually matters.
- **Deferred truth.** Three marks — your group, the UTC(k) you steer to, and UTC
  arriving later — with the third drawn as *not yet present*. Possibly two
  panels: at the moment of measurement, and after Circular T. This is the
  field-specific one nobody else can draw.
- **Stability versus accuracy.** The watch that keeps perfect time and is set
  three minutes fast: even tick spacing, wrong origin. A tick-mark timeline
  rather than a target, which usefully breaks the visual monotony.
- **Common-mode versus differential.** Two clock traces drifting together versus
  two drifting apart, with the *difference* plotted underneath in both cases.
  The difference trace is flat in one and not the other, which is the whole of
  the agreement argument in one more panel.
- **Compensated versus uncompensated path.** T1's diagram already exists as a
  slide; it wants redrawing to this house style and is the natural opener for
  *Transferring Time*.

## Rejected

- **Ring spacing for resolution.** Suggests the shot landed *on* a ring.
  Resolution quantises the report, not the event, so a grid is the honest
  metaphor.
- **A third axis for accuracy.** The whole point is that there isn't one.
